# Stream Loop

A phone-friendly streaming-dashboard UI prototype based on the provided screenshots. It includes Home, Setup Stream, Live, Videos, and Settings screens.

## Try it on your phone

Open [`index.html`](./index.html) from the repository using GitHub's file preview, or enable GitHub Pages for this branch/repository to host the prototype as a website. No Android Studio is needed to preview the UI.

## Important limitations

This is a front-end prototype, not a native Android application and not a working streaming encoder. The video selection stays in the browser and is not uploaded; the stream setup button only displays a demo message. Real live streaming requires a streaming implementation and a platform/server that accepts the broadcast. “Lifetime free” service cannot be promised: platform rules, bandwidth, mobile data, and hosting/relay costs or limits may apply. Never expose a real stream key in public code or screenshots.

## Included screens

- Home dashboard
- Stream setup with platform, title, masked stream key, video selection and loop toggle
- Live status placeholder
- Video library demo
- Settings and security notes
